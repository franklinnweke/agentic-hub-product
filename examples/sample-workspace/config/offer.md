# Offer: 25-Account Pipeline Sprint

Agentic Hub helps a small team turn a target list into evidence-backed lead briefs, human-reviewed follow-up drafts, and a weekly analytics report.

The first service offer is a supervised pipeline sprint:

- Import a curated target CSV.
- Produce account briefs with fit score, evidence, missing data, and recommended angle.
- Draft concise follow-ups that start in `needs_review`.
- Generate a weekly operating report from local state.

No outbound message is sent by the system. The operator reviews, edits, approves, and sends manually outside the MVP.
